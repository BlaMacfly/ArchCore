# assets-archonia — données du client (jamais publiées)

Place ici le contenu du dossier `Game` du client ArchLord 64 bits (`Archonia.exe`, `character/`,
`texture/`, `world/`, `ini/`…), ou un lien symbolique vers lui. ArchRust le cherche en premier
(`assets-archonia/Game` puis `assets-archonia/`), avant `../client/ArchLord/Game`.

**Tout ce dossier est ignoré par git** (sauf ce fichier) : ces fichiers appartiennent à l'éditeur
du jeu et ne doivent jamais être poussés sur GitHub, même convertis ou rangés ailleurs.

---

Put the `Game` folder of the 64-bit ArchLord client here (or a symlink to it). ArchRust looks here
first. **The whole folder is git-ignored** (except this file): these files belong to the game's
publisher and must never be pushed to GitHub, even converted or moved.
